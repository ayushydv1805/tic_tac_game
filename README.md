# Tic Tac Toe — Playfield

A responsive, browser-playable 2D Tic Tac Toe game based on the original C console game in this repository.

## Play it
Open **[the live game](https://ayushydv1805.github.io/tic_tac_game/)** after enabling GitHub Pages (Settings → Pages → Deploy from a branch → `main` / `/(root)`). You can also download this repository and open `index.html` in any modern browser.

## Features
- Two-player local mode
- Play against an unbeatable CPU using the minimax algorithm
- Scoreboard for X, O / CPU, and draws
- New round, undo move, and reset scoreboard
- Responsive 2D board with win-line animation
- No framework, build step, or dependencies required

## Files
- `index.html` — game layout
- `style.css` — visual design and responsive styling
- `game.js` — game rules, state, and CPU logic
- `tic tac.c` — original C console implementation

## Run locally
Simply open `index.html` in your browser.
